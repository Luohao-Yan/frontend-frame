Add the app-layer foundation: shared library build config, theme bootstrap,
typography/layout tokens, Container/PageSection/SectionBackdrop/DashedLine,
Reveal/Stagger motion presets, framework adapters, and multi-variant header
blocks with a live variant catalog. `app-kit` now also ships AppShell,
SkipLink, RouteBoundary, and ErrorBoundary for production route shells.
`forms` adds Zod-backed actions, fetch transport, submission state, and
server field-error mapping for React Hook Form. `blocks` now includes
interchangeable Header, Hero, Footer, and Pricing families with 10 stable
variants and per-variant subpath exports. `ui` also adds the WebGL
FlowGridBackground used by the production login-page template.
